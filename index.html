WolfCafe

WolfCafe is a full-stack restaurant ordering system designed to streamline menu management, order processing, and inventory tracking for café-style restaurants. The backend was built using FastAPI with a MySQL database, following Agile/Scrum principles throughout development. The system supports full CRUD operations for menu items, orders, and inventory, includes input validation and error handling, and is structured to scale for real-world restaurant workflows. This project emphasizes clean API design, collaborative teamwork, and practical software engineering practices.
